## 2. The Four-Step Prometheus Product Vertical

Prometheus guides organizations along a four-stage digital evolution—moving from initial public discovery to connected, secure, operational autonomy:

```
+------------------+     +--------------------+     +------------------+     +-------------------+
|  1. MARKETING    | --> |   2. FEDERATION    | --> |   3. SECURITY    | --> |  4. CRM / ERP     |
| Mission & Home   |     | Connected Nodes    |     | File-Based Safety|     | Operational Flow  |
+------------------+     +--------------------+     +------------------+     +-------------------+
```

### Step 1: Strategic Marketing — Mission Discoverability & Owned Publishing
* **Owned Digital Home:** Establishes your canonical web domain where pages, articles, events, and resources reside permanently—free from third-party algorithmic control or social platform lock-in.
* **Transparent Communication:** Articulates audience intent, products, services, and core mission values using clear, accessible presentation.
* **Privacy-Conscious Measurement:** Measures qualified inquiries and meaningful actions without intrusive user-surveillance scripts or engagement-maximizing algorithms.

### Step 2: Federation — Interoperable Network of Autonomous Nodes
* **Independent Node Ownership:** Each organization retains total ownership over its domain, content, identity, local policies, and governance.
* **Open Interoperability:** Uses versioned, open standards to link directory listings, public profiles, and shared initiatives without centralizing user data into a master database.
* **Consent & Exit Assurance:** Every federated link is permissioned. Members retain total freedom to modify shared feeds or exit the network without losing site functionality or data assets.

### Step 3: Security by Design — Responsible File-Based Protection
* **Eliminating Login & SQL Vulnerabilities:** Public publishing is file-based and static-rendered, removing database injection vectors, CMS administrative login exploits, and server-side bloat.
* **Git Version Control & Recovery:** Every site change is backed by Git, enabling instant rollback, offline local review, and complete revision history tracking.
* **Zero-Captcha Direct Communication:** Utilizes pre-structured client-side email drafts for inquiries, eliminating captcha friction while preventing automated spam bot processing.

### Step 4: CRM & ERP Workflows — Connecting Relationships to Operations
* **Traceable Ingestion Pipeline:** Public inquiries flow into consented contact records, which transition into service agreements, active project tasks, and operational delivery schedules.
* **Member-Scoped Records:** Customer and operational data remains private to the collecting organization—never merged into network-wide data pools.
* **Integrated Tooling:** Combines lightweight native registers (inbox, pipeline, project tracker) with modular exports to specialist accounting or CRM software when required.

## 3. Technology Architecture: AmadeusWeb Spring v9.9

The foundation powering DAWN and Prometheus is **AmadeusWeb Spring v9.9**—a mature, 7-year-old proprietary framework resulting from 25+ years of software refinement:

* **File-System Derived Navigation:** Site structure is mirrored directly from folder hierarchies (`Section -> Node -> Subnode -> Page`), generating dynamic contextual menus automatically without database queries.
* **Multi-Format Content Processing:** Natively parses Markdown, HTML, PHP scripts, TSV data sheets, Reveal.js slide decks, AI conversation exports, and structured forms.
* **Offline-First Development Workflow:** Teams edit content locally using standard tools (VS Code, TortoiseGit), review changes on local machines, and deploy via simple, secure FTP upload.
* **CDN & Asset Optimization:** Uses dedicated CDN mapping variables to serve heavy media assets (PDFs, images, videos) without bloating the core content repository.
* **Open Repository Transparency:** Public federated sites maintain public Git repositories, fostering open collaboration and verifiable content integrity.
